This release of the [fork](https://github.com/snargit/GoogleTestAdapter) integrates GTA's options into the new settings experience of Visual Studio 2026.

* enhancement: in Visual Studio 2026, GTA's options are part of the new settings UI (*Tools/Options/Google Test Adapter*, with the same pages and groups) and of its `settings.json` (e.g. `googleTestAdapter.testDiscovery.misc.testDiscoveryRegex`); existing options are taken over, and changes are also written back to where the options pages keep them, so they are preserved if an earlier version of GTA is installed. Visual Studio 2017 to 2022 show the options pages as before
* enhancement: values the new settings UI can not check (e.g. regexes which do not parse, or numbers out of range entered into `settings.json`) are ignored with a message in the *Tests* output pane, and the option keeps its previous value
* bugfix: option *Additional PDBs* validated its previous value instead of the new one, so that an invalid pattern was only reported when the option was changed again
