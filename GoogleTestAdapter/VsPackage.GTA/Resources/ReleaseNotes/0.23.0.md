This release of the [fork](https://github.com/snargit/GoogleTestAdapter) comes with a skill for coding agents, which diagnoses and configures GTA. See the [README](https://github.com/snargit/GoogleTestAdapter#agent_skill) for how to install it.

* enhancement: an [agent skill](https://github.com/snargit/GoogleTestAdapter#agent_skill) lets coding agents (Claude Code, Codex, GitHub Copilot in Visual Studio and VS Code, and the Copilot CLI) find out why tests or benchmarks do not show up or run as expected in Test Explorer, and configure GTA (options, solution and project settings); it asks GTA in the running Visual Studio with a PowerShell script, and comes as plugin for Claude Code, Codex, and the Copilot CLI (the repository is its marketplace), via `gh skill install`, and as `google-test-adapter-skill-<version>.zip` with each release
* enhancement: GTA's automation object lists the outputs of the solution's projects as Test Explorer gives them to the test adapters, with what GTA makes of each executable (`GetSolutionExecutables()`), and provides the text of the Output window's *Tests* pane (`GetTestOutput()`), which can not be read from outside Visual Studio otherwise
* enhancement: the automation object answers wrong calls with messages saying what to pass instead; note that it no longer accepts relative paths, which it resolved against Visual Studio's working directory
